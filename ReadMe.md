## 🚀 Projetos em Destaque

### 📦 Order Management API

API REST desenvolvida com **Node.js, TypeScript, Express, Prisma e PostgreSQL**, com foco em organização de código, regras de negócio, autenticação e boas práticas de desenvolvimento.

O projeto utiliza **Docker** para o ambiente de desenvolvimento e **GitHub Actions** para automação do fluxo de CI/CD.

Também está sendo utilizado como laboratório para aprofundar conhecimentos em **testes automatizados, testes unitários, testes de integração e TDD**.

🔗 [Repositório no GitHub](https://github.com/fsousanetto/order-management-api)

---

### 💰 Controle Financeiro

Aplicação Full Stack para gerenciamento financeiro desenvolvida com **Angular, Node.js, Express, Prisma e PostgreSQL**.

O projeto conta com autenticação, gerenciamento de transações financeiras e comunicação com uma API REST.

---

### 🌦️ Clima

Aplicação de previsão do tempo desenvolvida em **JavaScript** e **Node.js**, utilizando **SSR (Server-Side Rendering)** com template engine (**EJS/Mustache**) para renderização dinâmica. O sistema integra APIs de meteorologia e geolocalização do navegador para fornecer dados climáticos precisos e em tempo real com base na localização do usuário.
